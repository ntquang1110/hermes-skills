# Leadership Canvas — 9-Box Framework

A one-page leadership identity map, inspired by the Business Model Canvas but adapted for personal leadership development.

## The 9 Boxes

| # | Box | Question | Purpose |
|---|-----|----------|---------|
| 🎯 | **Mission** | Why do I lead? | Core purpose / "why people should follow me" |
| 🧭 | **Vision** | Where am I taking the team? | 1-3 year future picture |
| 💎 | **Values** | What do I stand for? | 3-5 non-negotiable principles |
| ⚡ | **Strengths** | What am I naturally good at? | Leadership superpowers |
| 🌱 | **Growth Areas** | What holds me back? | Blind spots to work on |
| 🎭 | **Style** | How do I lead? | Visionary / Coach / Democratic / Servant / Transformational |
| 🤝 | **Key Relationships** | Who matters? | Team, peers, mentors — who to influence, learn from, develop |
| 📊 | **Success Metrics** | How do I know I'm winning? | Team autonomy, self-initiation, ownership |
| 🌟 | **Legacy** | What will I be remembered for? | The long-term impact |

## When to Use

- **First coaching session:** Have the user fill this out → provides a complete leadership snapshot
- **Quarterly review:** Revisit → track changes, see growth
- **Before/after a leadership transition:** Capture the delta

## How to Use in Coaching

1. User fills all 9 boxes (in any order)
2. Look for **patterns**:
   - **Contradictions:** e.g. "Sai nhanh sửa nhanh" (value) vs "Chưa dám giao kết quả" (growth) → need tolerance for mistakes
   - **Vicious cycles:** e.g. "Not satisfied with output → do it myself → team dependent → trust low → more dissatisfied"
   - **Hidden strengths:** e.g. "High standards" + "detail-oriented" → can be a strength OR a trap depending on how used
3. Extract **3 contradictions + 3 actions** as coaching output
4. Save to project file + update dashboard

## Example: Real Canvas (Vietnamese — Leader with 3+ years experience)

| Box | Content |
|-----|---------|
| Mission | "Khỏe mạnh thế giới" — Help people eat well, stay healthy, avoid hospitalization |
| Vision | A world full of joy, health, green environment, free from disease |
| Values | Hiệu quả (Efficiency), Sai nhanh sửa nhanh (Fail fast fix fast), Khoa học dẫn đường (Science-led) |
| Strengths | High standards, detail-oriented, good solutions, people-reader |
| Growth | Slow decisions, afraid to delegate outcomes, low trust in team, need more communication |
| Style | Gets into details, doesn't share context/beliefs to enable team autonomy |
| Relationships | Team needs upgrade, current GM underperforms, team solution-dependent, no shared goals |
| Metrics | Team self-organizes, brainstorms, proposes and executes independently; team always has goals top-of-mind |
| Legacy | Team looks back happy about working together (not about me); I'm a facilitator and blocker remover, not a dependency |

## Key Coaching Insights from this Canvas

The most common pattern: **High standards + Low trust → Do it myself → Team dependent → Never develops → Loop.**

Break the loop by:
1. Give **context + goal**, not solutions
2. Ask **"What do you think?"** instead of giving answers
3. Start with small delegation → build trust gradually
4. Define clear deliverables + deadlines (shared sheet)
5. Weekly 1-1s: "What did you learn?" instead of "What did you do?"
