# Session Examples — Deterministic Hybrid Architecture

## Open Code Review (OCR) by Alibaba

Repo: github.com/alibaba/open-code-review (Apache-2.0, 37.8k stars)
Paper: arXiv 2609.20519

Architecture:
- Deterministic: selectFiles() (path/extension/size gates), groupDiffs() (semantic bundling), rule matching (sniffer.go), positioning/reflection (llmloop/)
- LLM: actual code review with scenario-tuned prompts and toolset
- Result: 44-49% fewer tokens than pure-LLM agent, higher precision, lower recall

Key lesson: "Việc nào có đáp án đúng thì để code tất định lo, việc nào cần suy xét thì mới gọi model."

## SoL-Pi by NVIDIA Labs + MIT

Repo: github.com/NVlabs/SoL-Pi
Paper: arXiv 2609.20519, Sep 17, 2026

4 surviving mechanisms from 152 proposals:
1. Action Fusion — combine edit + run command into 1 tool call (deterministic harness)
2. Online Context Compact — compress at subtask boundaries (deterministic harness)
3. ObservationPack — archive tool output, keep handle + excerpt (deterministic harness)
4. Evidence-Preserving Reducer — delegate log reading to cheaper agent, verify quotes (LLM)

3/4 are deterministic harness engineering. Only 1 uses LLM.

EdgeBench results: 94% of baseline score, 45-49% fewer tokens, ~33% cost reduction.

## Hermes Token Usage Analysis (Quang's system, Sep 2026)

30-day totals from state.db:
- 208M tokens (189M input + 19M output)
- 2,436 API calls across 1,909 sessions
- Cost: $0 (all free tier providers)

Breakdown by source:
- Cron: 56% (116M tokens, 1,674 sessions)
- Telegram: 38% (79M tokens, 130 sessions)
- Subagent: 5% (10M tokens, 72 sessions)

Top cron consumers:
- KFlow Push (every 30min): 1,149 sessions, 44.9M tokens (21.5%)
- Knowledge Researcher (every 4h): 204 sessions, 33M tokens (15.8%)
- Auto Threads (daily): 30 sessions, 10M tokens (4.8%)

Optimizations applied:
1. KFlow Push: every 30min → every 2h (saves ~33M tokens/month)
2. Prompt trimming: knowledge-researcher (500→100 words), Auto Threads (300→80), Tâm lý (400→80 each)
3. Compression config: threshold 0.5→0.3, target_ratio 0.20→0.15, protect_last_n 20→30
4. AGENTS.md created with ObservationPack/Action Fusion/Context Compact instructions

Estimated savings: ~33M tokens/month from cron + ~15-20% from compression = ~50-60M tokens/month (25-30% of total)
