# Design System: GSAP

> **Hermes Agent — Implementation Notes**
> 
> Uses Mori (sub: Inter Tight, Söhne, DM Sans).
> ```html
> <link href="https://fonts.googleapis.com/css2?family=Inter+Tight:wght@400;600&display=swap" rel="stylesheet">
> ```

**Theme:** dark | **Vibe:** Animated chalkboard in a design studio

## Color Palette
- **Just Black** `#0e100f` — Page canvas
- **Surface Cream** `#fffce1` — Primary text, button borders
- **Surface 50** `#7c7c6f` — Muted text
- **Surface 25** `#42433d` — Hairline borders
- **Off Black** `#191919` — Nested panels
- **Discipline colors:** Green `#0ae448` (GSAP), Orange `#ff8709` (SVG), Pink `#fec5fb` (Scroll), Lilac `#9d95ff` (Text), Blue `#00bae2` (UI)

## Typography
- **Single face:** Mori (sub: Inter Tight), weights 400, 600
- **Scale:** Minor Third (1.2) from 20px base. Display up to 224px!

## Spacing & Shape
- **Base unit:** 4px | **Max width:** 1280px | **Section gap:** 80px
- **Radius:** cards 8px, buttons 100px (pill), tags 8px

## Key Rules
- Ghost pills with 1px cream border — no filled CTAs
- 224px headline with lh 0.9 and -0.02em tracking
- 5 discipline colors as taxonomy
- Curly-bracket `{ }` annotations on every section
- Cream on black — never reversed
- No drop shadows — gradient washes for depth
