# Design System: Slush

> **Hermes Agent — Implementation Notes**
> 
> Uses Lateral (sub: Druk, Bowlby One, Antonio) + Aeonik Pro (sub: Inter, Satoshi).
> ```html
> <link href="https://fonts.googleapis.com/css2?family=Inter:wght@500;700&family=Antonio:wght@500;600;700&display=swap" rel="stylesheet">
> ```

**Theme:** light | **Vibe:** Inflatable sticker universe on pastel paper

## Color Palette
- **Carbon** `#000000` — Text, borders, filled CTA
- **Paper White** `#ffffff` — Canvas, card surfaces
- **Sky Wash** `#dceeff` — Hero background
- **Electric Blue** `#4da2ff` — 3D ribbon decorative
- **Mint Pop** `#55db9c`, **Lavender** `#e9ccff`, **Ember** `#fb4903`, **Sunburst** `#ffd731`, **Voltage Violet** `#5c4ade` — Sticker palette

## Typography
- **Display:** Lateral (sub: Druk/Antonio), weight 800 only
- **UI:** Aeonik Pro (sub: Inter), weights 500, 700
- **Scale:** Minor Third (1.2) from 20px base. Display up to 640px!

## Spacing & Shape
- **Base unit:** 4px | **Max width:** 1440px | **Section gap:** 48px
- **Radius:** nav/buttons 1600px (pill), cards 20px, elevated 40px

## Key Rules
- Lateral 800 with crushed lh 0.75-0.80 for sculptural text
- 1px #000000 borders everywhere — hand-cut sticker feel
- 6-color palette used together — not one accent
- No gradients — 3D ribbons carry dimension
- No box-shadows — color bands for elevation
