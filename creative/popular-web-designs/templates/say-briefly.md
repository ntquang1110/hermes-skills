# Design System: Say Briefly

> **Hermes Agent — Implementation Notes**
> 
> Uses Bricolage Grotesque (sub: Archivo Black, Mulish 900) + Inter + Roboto Mono.
> ```html
> <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700&family=Bricolage+Grotesque:wght@800&family=Roboto+Mono:wght@400&display=swap" rel="stylesheet">
> ```

**Theme:** light | **Vibe:** Creative agency sketchbook on cream paper

## Color Palette
- **Forest Ink** `#1a3300` — Primary text, CTA buttons, borders (structural backbone)
- **Highlighter Yellow** `#ffe95c` — Text highlight wash, badge fills
- **Sticky Note Teal** `#a8e5e5` — Accent card fill
- **Sticky Note Mint** `#d5f5c2` — Accent card fill
- **Sticky Note Blush** `#f6d0ff` — Decorative fill
- **Terracotta** `#cb5521` — Warm accent
- **Cream Paper** `#fcfaf5` — Page canvas
- **Forest Ink** `#1a3300` — Primary text

## Typography
- **Display:** Bricolage Grotesque (sub: Archivo Black), weight 800 only
- **UI:** Inter, weights 300-700
- **Code:** Roboto Mono, weight 400
- **Scale:** Minor Third (1.2) from 15px base. Display up to 90px

## Spacing & Shape
- **Base unit:** 8px | **Max width:** 1200px | **Section gap:** 64px
- **Radius:** buttons 6px, cards 12px, nav 16px

## Key Rules
- Forest Ink #1a3300 for all primary text and CTAs
- Bricolage Grotesque 800 with positive tracking 0.04-0.05em
- Highlighter Yellow as text wash — never CTA fill
- 6px radius buttons, 12px cards
- No pure black — Forest Ink is the text color
- Pastel accents as individual cards only
