## Lưu ý
- Luôn `aria-hidden="true"` — icon trang trí
- Icon thay status phase: dùng dot màu 8px (`<span style="display:inline-block;width:8px;height:8px;border-radius:50%;background:#HEX"></span>`) thay vì icon glyph — phase → màu (planning=#FFD600, review=#3B82F6, done=#22C55E, testing=#8B5CF6, idle=#8B8B8F)
