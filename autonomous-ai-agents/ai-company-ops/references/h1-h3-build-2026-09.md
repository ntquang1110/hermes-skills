### PITFALL 1 — WS receive_bytes() đưa NHIỀU frame trong 1 message
`StreamSession.feed()` ban đầu chỉ xử lý frame đầu (`raw[:FRAME_BYTES]`) → test
gửi 1 message chứa 20 frame → chỉ đủ 1 frame → không bao giờ flush. **Fix: loop
qua toàn bộ message** `for off in range(0,len(raw),FRAME_BYTES): _feed_frame(frame)`.

### PITFALL 2 — slice index phải là int
`OVERLAP_S * FRAME_SAMPLES` = `1.0 * 1600` = **1600.0 float** → `pcm[-s*4:]` ném
`slice indices must be integers`. Fix: `s = int(OVERLAP_S * FRAME_SAMPLES)`.
Triệu chứng: WS client bị đóng "no close frame" vì vòng lặp server crash.

### PITFALL 3 — SimpleHTTPRequestHandler endpoint: JSON body vs form-urlencoded
Dashboard 8090 (`server.py`) ban đầu chỉ đọc JSON body; frontend gửi
form-urlencoded → 400 "thiếu task_id". **Fix: chấp nhận CẢ 2** —
```python
params = json.loads(body) if body.strip().startswith("{") else {}
if not params and body and "form" in self.headers.get("Content-Type",""):
    import urllib.parse as u; params = dict(u.parse_qsl(body))
```

## Bài học delegation (quan trọng)
Subagent báo "code xong / C3 chưa verify" là TỰ BÁO CÁO, không phải sự thật.
Luồng H2 subagent để lại `app/main.py` + `server.py` **sửa nhưng chưa commit/push**
và server **chưa restart** → endpoint approve 404/405 trên server đang chạy.
Parent PHẢI: re-read những file subagent đụng → verify endpoint chạy thật (curl)
→ questart server → commit+push phần dở → revert task thử nghiệm về trạng thái
trước (không để self-approve làm thay Quang). Không tin "xong" khi chưa tự chạy.
