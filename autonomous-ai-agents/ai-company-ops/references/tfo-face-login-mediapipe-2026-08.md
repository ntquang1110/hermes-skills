## Face Login — MediaPipe (2026-08, on-premise, thay passcode)

Anh Quang chốt: xác minh khuôn mặt thay passcode (sau khi research Faceplugin SDK — nặng Torch 2GB + license mơ hồ → chọn MediaPipe).

- **MediaPipe 1.0.0 đổi API QUAN TRỌNG:** `mp.solutions.face_mesh` KHÔNG CÒN — `AttributeError: module 'mediapipe' has no attribute 'solutions'`. Phải dùng **Tasks API**: `from mediapipe.tasks import python as mp_python; from mediapipe.tasks.python import vision` + `FaceLandmarkerOptions` + `vision.FaceLandmarker.create_from_options(options)`, running_mode=IMAGE.
- Model cần download 1 lần: `https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task` → lưu `app/face_landmarker.task` (cơ chế `_ensure_model()` tự download khi chạy lần đầu).
- Embedding = **478 landmarks** (x,y,z), chuẩn hóa: trừ centroid → chia norm (bất biến khoảng cách camera). So sánh = cosine similarity, ngưỡng match **0.93**.
- File: `app/face_auth.py` — `extract_embedding(bytes)`, `compare_embeddings(e1,e2)`, `is_match(sim)`. Ảnh vào: bytes → cv2.imdecode → cvtColor BGR2RGB → `mp.Image(format=SRGB, data=rgb)`.
- API (`app/main.py`): `POST /api/face/enroll` (ảnh + token → lưu `face_embedding.json` vào user workspace), `POST /api/face/verify` (ảnh + **email HOẶC token** → match → TỰ TẠO session token trả về), `GET /api/face/status`.
- **AUTO-LOGIN 1:N (2026-08 — "cứ lắp khuôn mặt thì auto-login bằng email"):** `POST /api/face/login` nhận ảnh → **duyệt TẤT CẢ `users/*/face_embedding.json`** → lấy similarity cao nhất → nếu >= 0.93 → tạo session token + set cookie + trả `{token, email}`. User không cần nhập email. Frontend màn login bỏ ô email, chỉ camera + nút xác minh. Email decode: `d.name.replace("_at_","@").replace("_dot_",".")`.
- **Enroll UX (anh kẹt khi "passcode xong quay lại kiểu gì"):** nút **📸 Lưu khuôn mặt** phải có NGAY TRONG app sau khi login (header menu) — `quickEnroll()` bật modal camera + enroll bằng token hiện tại, KHÔNG bắt user logout rồi mới enroll. Menu 3 chấm `•••` gom: 📸 Lưu khuôn mặt + 🔒 Khóa (bỏ badge "Luôn lắng nghe" — anh yêu cầu).
- **Pitfall verify trước login:** user chưa có token khi đứng ở màn login → verify phải nhận `email` field (không chỉ token). Khi match → server tự tạo session token + trả về, frontend lưu localStorage.
- **PITFALL face login treo "đang nhận diện" (2026-08-12, Quang báo):** triệu chứng = bấm xác minh → treo mãi. Nguyên nhân: `app/face_auth.py` import numpy/cv2/mediapipe FAIL (`ModuleNotFoundError: No module named 'numpy'`) → `/api/face/login` trả 500 → frontend không nhận response → hiện "đang nhận diện" mãi. Fix: cài vào `.venv` bằng script subprocess (`python scripts/xxx.py` gọi `.venv/Scripts/python.exe -m pip install numpy opencv-python-headless mediapipe` — KHÔNG gọi `.venv` python trực tiếp trong terminal, lifecycle guard chặn "embedded null character"). Check nhanh khi nghi: `grep -i "face_auth" logs/tfo_server.log | tail -5` — nếu thấy traceback import → thiếu deps.
- **UI login 2 tab:** 😀 Khuôn mặt (mặc định — webcam + nút Xác minh + nút 📸 Lưu khuôn mặt) | 🔑 Passcode (backup). Enroll cần token đã login (hướng dẫn: login passcode → 🔒 Khóa → enroll).
- **FACE AUTO-LOGIN — không cần bấm (build 12/08, Quang: "cứ đúng khuôn mặt thì tự vào"):** `login.html` `startAutoScan()` → setInterval 2s → chụp frame từ video → POST `/api/face/login` → `d.matched && d.token` → lưu token + redirect `/app`. Cờ `scanning`/`matchedDone` chống chồng gọi; `stopAutoScan()` khi match/tab passcode; 422 "chưa thấy khuôn mặt" → im lặng scan tiếp (không spam lỗi); chưa enroll → hint 1 lần "dùng Passcode vào rồi lưu khuôn mặt (menu ⋯ → 📸)" qua `window._noFaceHintShown`. Nút Xác minh thủ công giữ làm fallback.
- **Nút 🔒 Khóa (logout)** trên header: xóa token localStorage + gọi `/api/logout` + hiện lại màn login + bật camera — anh hỏi "có nút Lockout đâu hả em" khi không tìm được cách quay lại màn login.
- **Liveness chớp mắt = đau đầu:** spike của Claw bắt chớp mắt quá khắt khe → anh không qua được. Bản tfo KHÔNG có liveness (chấp nhận cho MVP pilot); nếu cần chống fake ảnh, thêm liveness sau nhưng phải cho retry rộng rãi.
- Ảnh khuôn mặt = embedding local (478 điểm, KHÔNG phải ảnh gốc) — không gửi cloud, đúng chuẩn privacy TFO.
