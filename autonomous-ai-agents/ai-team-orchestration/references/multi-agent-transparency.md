# Multi-Agent Transparency Architecture

How to make agent work visible to the user. Quang's requirement: "anh muốn thấy được đâu ra của từng task và agent đã trả lại cho CEO như nào".

## Three-Layer Transparency

```
Layer 1: Activity Log (JSONL)
  └─ Every agent step → logs/activity.jsonl
  └─ Dashboard reads get_recent(15) for live feed
  └─ Per-task: get_task_activity(task_id) for report

Layer 2: Task HTML Report
  └─ Each completed task → tasks/{task_id}/report.html
  └─ Sections: Task Info, Activity steps, Result summary, Raw JSON
  └─ Served at GET /task/{task_id} on dashboard server

Layer 3: Dashboard (Web)
  └─ Agent status (idle/pending/busy/error) with colored dots
  └─ CEO inbox (message queue with unread count)
  └─ Activity feed (last 10-15 steps across all agents)
  └─ Task list with "Report →" links to HTML reports
  └─ Metrics: agents count, idle, pending tasks, completed
  └─ Auto-refresh every 10s
```

## Key Files

| File | Purpose |
|------|---------|
| `activity.py` | `log()`, `get_recent()`, `get_task_activity()`, `clear()` |
| `tasks/report.py` | `generate_report(task_id)` → HTML file |
| `dashboard/server.py` | HTTPServer serving HTML + JSON API |
| `dashboard/index.html` | Dashboard UI with JS auto-refresh |
| `logs/activity.jsonl` | Append-only JSONL activity stream |

## Activity Log API

```python
from activity import log, get_recent, get_task_activity

log("research", "analyzing", "Analyzing request: EZ80 vs DirectVet", "T-001", "busy")
log("research", "analysis_complete", "Analysis done", "T-001", "done")

recent = get_recent(15)           # Last 15 entries across all agents
task_log = get_task_activity("T-001")  # All entries for one task
```

Each log entry: `{ts, timestamp, agent, action, detail, task_id, status}`

## Task Report Generator

```python
from tasks.report import generate_report
path = generate_report("T-001")  # → tasks/T-001/report.html
```

Uses `REPORT_TEMPLATE` with sections:
1. Task Info: title, description, context, deadline, handled_by, finished_at
2. Activity Log: per-task steps with timestamps + agent names
3. Result: summary text (the actual output)
4. Raw Data: JSON dump for debugging

## Dashboard Server Endpoints

| Route | Method | Returns |
|-------|--------|---------|
| `/` | GET | index.html |
| `/data` | GET | JSON: `{agents, inbox, activity, tasks, stats}` |
| `/task/{id}` | GET | HTML report for task |
| `/dispatch` | POST | Dispatch result |

## Pitfalls

- **Wire transparency BEFORE claiming multi-agent is done.** Quang will check immediately.
- **Dashboard process dies silently** on Windows. Restart: `cd ~/ai-company-v2 && python dashboard/server.py 5050` in background.
- **cpython 3.14 `~` fails** as python arg. Use `cd ~/... && python ...` instead.
- **Tunnel must be restarted** after server restart. Use `lt --port 5050 --subdomain <name>`.
- **Task HTML reports** are auto-generated by `worker_v2._generate_report()` — if this fails, check `report.py` import path.
- **Activity log file** can grow. Keep MAX_ENTRIES=1000 in `activity.py`.
