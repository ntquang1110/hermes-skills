# Leadership Mastery Curriculum (Real Session Reference)

This is a complete 10-module leadership curriculum built for an experienced
leader (Vietnamese-speaking, mid-senior level) who wanted to become an
"Influential Leader." Use as a starting template for any leadership coaching
request.

## User Profile (from session)
- **Level:** Leader of several years, managing a team with weak expertise
- **Priority:** People management & talent retention
- **Values:** Efficiency, speed, decisional autonomy
- **Gap:** Decisiveness & influence
- **EQ Reality:** Reacts more than responds; doesn't work enough WITH the team
- **Root Cause:** Team is weak → leader does everything → no time to lead →
  less influence → harder to retain talent

## Module Sequencing (10 modules)

| # | Module | Why This Order |
|---|--------|----------------|
| 1 | Self-Mastery — Foundation | Always start here |
| 2 | Building Trust & Credibility | Prerequisite for influence |
| 3 | Communication & Influence | Directly addresses "not influential enough" |
| 4 | ★ People Management & Talent Retention | User's #1 priority |
| 5 | High-Performance Teams | Build on retention |
| 6 | Difficult Conversations & Feedback | Needed when upgrading team |
| 7 | Vision, Strategy & Execution | Next level |
| 8 | Resilience & Leading Through Change | For sustainability |
| 9 | Scaling Leadership & Culture | Growth stage |
| 10 | Legacy & Continuous Growth | Capstone |

## Module Structure Template

Each module follows this exact 4-part format:

```
## 📖 1. Core Theory
[Framework or model — short, memorable, with a table or diagram]

## 🎯 2. Case Study
[Real leader example — situation → action → result → lesson]

## ✍️ 3. Reflection Questions
[5 targeted questions that force self-application]

## ✅ 4. Action Tasks
[2-3 concrete tasks to complete before next module]
```

## Example: Module 1 Content Structure

### Core Theory: LEADER FROM WITHIN framework
```
L = Limiting Beliefs
E = Emotional Triggers
A = Authentic Values
D = Daily Habits
E = Energy Management
R = Reflection
```

### Core Theory: EQ 5 Components (Goleman)
| Component | Self-Check Question |
|-----------|---------------------|
| Self-Awareness | How am I feeling right now? |
| Self-Regulation | Am I over-reacting? |
| Motivation | Why do I do this? |
| Empathy | What is the other person feeling? |
| Social Skills | How can I connect better? |

### Case Study: Satya Nadella at Microsoft
- Problem: "know-it-all" toxic culture, $300B cap
- Action: Empathy reading → "know-it-all → learn-it-all" → admit mistakes
- Result: $2,500B cap, innovation culture
- Lesson: Leader's self-mastery = organization's culture

### Reflection Questions
1. Trigger map: what makes you lose composure with your team?
2. Values audit: top 3 values you want your team to feel from you
3. Leadership gap: strongest skill? weakest skill?
4. EQ check: when did you react vs respond this month?
5. Best colleagues: what did the best people you've worked with share?

### Action Tasks
1. Write Personal Leadership Canvas (1-page mission statement + values)
2. Feedback Friday — ask 2 team members "what should I stop/start/continue?"
3. EQ Journal — 7 days, daily entry on emotional situations

## Key Insights from Analysis Phase

When analyzing a user's reflection, watch for:

1. **The Trap Cycle:** "Output not good → do it myself → less leading → less influence"
2. **Value-Gap Contradictions:** User values "decisional autonomy" but admits
   "not decisive enough" — this signals a confidence/team problem, not a skill problem
3. **Root Cause Laddering:** "Best person on team has weak expertise"
   → this is THE bottleneck → everything else branches from it
4. **Re-prioritization:** If reflection reveals team weakness, bump
   "Difficult Conversations" and "People Management" up the order
