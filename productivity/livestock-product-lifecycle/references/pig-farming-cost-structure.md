# Pig Farming Cost Structure — Vietnam (research 16/09/2026)

Condensed cost data for pig fattening and sow breeding operations in Vietnam, sourced from Farmvina, GreenFeed, CP, MSD, and Vua Kiềm internal data. All costs are 2024-2026 estimates for Northern Vietnam. Use as reference data when building cost-structure boards.

## Source Classification

| Code | Meaning | Example |
|------|---------|---------|
| FACT | Official data, government, international orgs | TCTK, IMARC, Nghi dinh 211 |
| EVIDENCE | Published research, manufacturer data | GreenFeed price list, MSD vaccine catalog |
| INFERENCE | News, forums, aggregators | nguoichannuoi.vn, thanhtienco.vn |
| ESTIMATE | Internal Vua Kiem / Hermes projection | EZ80 cost estimates, stage allocations |

## 2. Sow Breeding Process

### Lifecycle

| Stage | Duration | Key Activity | Key Risk |
|-------|----------|-------------|----------|
| N1. Hau bi | 5-6 months (100-130kg) | Chon giong, vaccine nen | Phat hien dong duc lan dau |
| N2. Phoii giong + mang thai | 114 days | AI 2-3 lan, chia 0-90d/90-114d | Tao bon, say thai, mycotoxin |
| N3. De + nuoi con | ~7d pre + 28d nursing | Farrowing, MMA prevention | De kho, MMA, sot sua |
| N4. Cai sua -> tai phoi | 4-7 days | Flush feeding, PG600 if needed | Anestrus, nai gay |
| N5. Loai thai | 4-6 lua (~2-3 years) | Thay dan 20-40%/nam | |
