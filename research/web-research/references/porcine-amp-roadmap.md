## Pathway interaction map

```
Butyrate → TLR2/EGFR → MAPK → pBD3, pEP2C
                              → Nrf2 → pBD2 (antioxidant + barrier)
LPS/TLR4 → NF-κB → Cathelicidin, PR-39
PR-39 → ↓ NF-κB, ↓ MAPK (feedback anti-inflammatory)
pBD2 → ↓ Akt → ↓ Caspase-3/9 → ↓ Apoptosis
pBD2 → ↑ ZO-1, Occludin, Claudin → ↑ Barrier function
AMPs → Direct killing → ↓ Pathogens → ↑ Microbial diversity
```
