# 3-Product Disinfection Framework — Formulation Reference

Compiled October 2026 based on pH mechanism research (291 PubMed) + market analysis of 14 products in Vietnam.

## The product strategy

Three products covering the full spectrum of barn disinfection needs, at 1/3 to 1/10 the cost of imported alternatives:

### SP1: Chuồng trống (empty barn) — pH 13-14

| Property | Value |
|---|---|
| Active ingredients | KOH 2% + Ca(OH)₂ 10% suspension + Surfactant 0.5% |
| pH | 13-14 |
| Form | Powder to dissolve, or concentrated liquid |
| Efficacy | 54/60 pathogens (90%) on clean surfaces |
| Production cost | ~5k/L |
| Selling price | 8-15k/L |
| Comparable products | Vôi bột 3-8k/kg (pH 12.4, weaker), TH4+ 80-150k/L, Virkon 180-300k/kg |
| Safety | Eye/skin burns. Full PPE required. Neutralize with citric acid 5%. |
| Application | 200-300 ml/m². Pre-clean organic matter. Let dry 2-4h. |

**Mechanism:** KOH provides pH 13-14 → saponification + protein denaturation + RNA cleavage + proton gradient collapse. Ca(OH)₂ acts as alkali reservoir: when OH⁻ is consumed, undissolved Ca(OH)₂ dissolves to buffer pH. This maintains efficacy longer than NaOH alone.

### SP2: Xịt có lợn (occupied barn) — pH 3-4

| Property | Value |
|---|---|
| Active ingredients | Acid citric 5% + Thymol 1% + Tea tree oil 0.5% + Eucalyptol 0.3% + Lecithin 1% |
| pH (concentrate) | 3-4 |
| Dilution | 1:20 with water |
| Efficacy | 30-40/60 pathogens (safe for pigs) |
| Production cost | ~22k/L |
| Selling price | 35-60k/L |
| Comparable products | Anolyte 200-500k/L, Tinh dầu thảo dược 200-500k/L (5-10x cheaper) |
| Safety | Safe for pigs at proper dilution. No burns. |

**Mechanism:** Acid weakens bacterial membranes → essential oils penetrate more easily (synergy). Thymol disrupts membrane physically. Tea tree kills fungi. Eucalyptol supports respiratory tract.

### SP3: Xử lý nước uống (drinking water) — pH 4.5-5.5

| Property | Value |
|---|---|
| Active ingredients | Acid formic 5% + Acid citric 3% + Tannin 1% + Thymol 0.3% |
| pH (concentrate) | 2-3 |
| Dose | 3-5ml/L water → target pH 4.5-5.5 |
| Efficacy | 60-80% reduction E. coli/Salmonella in water |
| Production cost | ~12k/L |
| Selling price | 20-35k/L |
| Comparable products | Imported acid products 80-150k/L (3-5x cheaper) |
| Safety | Not for pigs <7kg. Use plastic pipes (acid corrodes metal). |

**Mechanism:** Acid lowers water pH → inhibits all bacteria. Tannin blocks E. coli fimbriae adhesion (physical mechanism). Thymol kills acid-resistant strains.
